# 12. Комбинации признаков

## Гипотезы до запуска

К исходным 155 признакам добавляются 12 комбинаций. Формулы фиксируются до измерения MAE и не используют PSNR, имена файлов, другие варианты исходника или статистики по всему набору.

| Комбинации | Число | Гипотеза |
|---|---:|---|
| Дисперсия лапласиана / (дисперсия яркости + 1), масштабы 1, 2, 4 | 3 | Отделить резкость от контраста сцены |
| Дисперсия лапласиана на соседних масштабах: 1/2 и 2/4, со слагаемым 1 в знаменателе | 2 | Описать изменение высоких частот при уменьшении масштаба |
| σ Хаара / (σ яркости + 1) | 1 | Описать шум относительно контраста сцены |
| σ Хаара / (среднеквадратичная оценка Immerkaer по RGB + 0,1) | 1 | Отделить шум от структурных границ по расхождению двух оценок |
| p99 градиента / (p50 градиента + 1) | 1 | Сравнить сильные границы с типичным перепадом |
| Энергия колец спектра 5–7 / (энергия колец 0–2 + 1e-8) | 1 | Описать баланс высоких и низких частот |
| Средний модуль высокочастотных DCT / (низкочастотных DCT + 1) | 1 | Описать баланс частот локальных блоков |
| Доля пропусков и зубчатость гистограммы × (p99 − p01) / 255 | 2 | Учесть диапазон яркости при описании изменения уровней |

Число столбцов на входе базовых моделей: 155 → 167. Исходная таблица `features/features.csv.gz` не меняется: комбинации вычисляются после её чтения при `features.combinations: true`. При повторном извлечении из изображений в таблицу по-прежнему записываются 155 признаков.

## Сравнение

Контроль и эксперимент выполняются в одном окружении на одном коммите. В каждом — пять базовых моделей из `experiments/ensemble_base.yaml` и четыре ансамбля из `experiments/ensemble.yaml`. Эксперимент с комбинациями задан в `experiments/combinations.yaml`; параметры моделей не меняются.

Оба варианта используют `StratifiedGroupKFold`, 5 фолдов, 10 бинов PSNR, seed 42. Предобработка обучается внутри фолдов. Прогнозы двух CNN берутся из прогона 09 без повторного обучения. Главный результат — изменение MAE стекинга на прогнозах; дополнительно сравниваются базовые модели, разброс по фолдам и ошибка по типам искажения. Выбор лучшей строки на тех же фолдах даёт оптимистичную оценку; при небольшом выигрыше потребуется проверка устойчивости на другом разбиении, прежде чем заявлять обобщаемое улучшение. Полная проверка на другом seed потребует согласованных OOF-прогнозов CNN для этого seed.

Новые комбинации не считаются полезными заранее. При отсутствии выигрыша сохраняется отрицательный результат, а текущая модель на 155 признаках остаётся основной. Последующие изменения формул считаются отдельными экспериментами.

## Запуск

Скрипт `C:\Neuro_rsreu\курсач\kaggle\combinations_run\run_combinations.py` клонирует точный коммит, запускает тесты, контроль, эксперимент и сохраняет `comparison.csv`, конфигурации, версии библиотек, результаты и прогнозы обоих вариантов. Пересчёт по изображениям и GPU не нужны. Сабмит автоматически не отправляется.

Отрицательное изменение означает улучшение. Контроль на 155 признаках пересчитан в этом же запуске; сравнение выполняется с ним, а не с немного отличающимися цифрами прогона 11. Все MAE повторно проверены по сохранённым OOF-прогнозам; проверены также выбранные прогнозы для сабмита и число строк test (3310).

### Устойчивость результата

Стекинг на прогнозах улучшился на 3 фолдах из 5. Изменения MAE по фолдам: +0,004875; −0,003536; −0,000243; +0,000339; −0,002897. Средний выигрыш 0,000293 (около 0,065 %) мал относительно этих изменений. По одному такому разбиению нельзя заявлять устойчивое улучшение.

Из пяти базовых моделей средняя ошибка уменьшилась только у CatBoost: 0,646206 → 0,643260. Он тоже улучшился только на 3 фолдах из 5; большая часть выигрыша пришлась на один фолд. LightGBM, XGBoost и обе MLP ухудшились.

По типам искажения у стекинга изменения составили примерно: `_1` −0,000122, `_2` −0,001103, `_3` +0,000013, `_4` −0,002369, `_5` +0,002115. Выигрыш на изменении уровней и шуме частично компенсируется ухудшением на изменении размера.

### Решение

Этот набор из 12 комбинаций не показал убедительного общего выигрыша. Основная конфигурация и таблица из 155 признаков сохраняются. Комбинации остаются отдельным воспроизводимым экспериментом, а не обязательной частью основного пайплайна. Новый сабмит на Kaggle не отправлялся. Следующий пункт работы — дополнить ансамбли линейной регрессией и Ridge, затем подготовить итоговые графики и общий ноутбук.

### Файлы

`comparison.csv` — парное сравнение девяти моделей; `fold_comparison.csv` — MAE по каждому фолду; `outputs/baseline/` и `outputs/combinations/` — результаты, OOF-прогнозы, прогнозы на test и сабмиты; четыре `run_*.yaml` — фактические конфигурации; `versions.json` — версии библиотек и коммит; `psnr-iqa-feature-combinations.log` — журнал Kaggle. Скрипт запуска, его проверки и метаданные запуска сохранены рядом.
