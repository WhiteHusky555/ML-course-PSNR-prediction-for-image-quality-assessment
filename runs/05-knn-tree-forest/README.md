# 05. KNN, решающее дерево и случайный лес

В основной конфиг добавлены сетки KNN, решающего дерева и Random Forest, всего 82 модели вместе с линейными. В исследование валидации добавлены те же модели на разбиении без группировки по исходнику. В таблицы результатов добавлен столбец `train_mae` — средняя по фолдам ошибка на обучающей части; разница между ним и MAE на проверке показывает степень переобучения.

| Модель | Сетка | Моделей |
|---|---|---|
| KNN | `n_neighbors` 3, 5, 10, 20, 50, 100; `weights` uniform и distance; `metric` euclidean и manhattan | 24 |
| Решающее дерево | `max_depth` 3, 5, 10, 20, без ограничения; `min_samples_leaf` 1, 5, 20, 100 | 20 |
| Random Forest | 300 деревьев; `max_features` sqrt, 0,33, 0,5; `min_samples_leaf` 1, 3, 10 | 9 |

Для KNN используется та же предобработка, что для линейных моделей: без масштабирования расстояние определялось бы признаками с наибольшим масштабом. Деревья не зависят от монотонных преобразований признаков и получают их без изменений.

Прогон выполнялся в приватном ядре Kaggle на CPU (4 ядра, Python 3.13). Ядро записывает версии библиотек, запускает тесты, затем `main.py` с основным конфигом и с каждой конфигурацией из `experiments/` и в конце пересчитывает признаки для 25 изображений и сравнивает их с таблицей `features/features.csv.gz`. Модели оцениваются кросс-валидацией `StratifiedGroupKFold` на 5 фолдах: стратификация по 10 бинам PSNR, группировка по исходнику, чтобы варианты одного снимка не попадали одновременно в обучение и проверку. Метрика — MAE в дБ на 13 210 изображениях train, у каждого исходника 5 вариантов искажения (`_1` — размытие, `_2` и `_3` — шум, `_5` — сжатие).

| Конфигурация | Моделей | Время |
|---|---|---|
| `config.yaml` | 82 | 95 мин |
| `experiments/categorical.yaml` | 16 | 16 с |
| `experiments/preprocessing.yaml` | 47 | 1,3 мин |
| `experiments/validation.yaml` | 50 | 49 мин |

## Результат

* 40 тестов пройдены. Прогон занял 2 ч 27 мин, из них около 71 минуты — перебор Random Forest в основном конфиге.
* Лучшая модель — Random Forest с `max_features` = 0,33 и `min_samples_leaf` = 3: MAE 0,688 при разбросе по фолдам 0,004 и ошибке на обучении 0,32. Сабмит на Kaggle: 0,63348 на public, 0,66349 на private.
* Лучший KNN — манхэттенское расстояние, 20 соседей, веса по расстоянию: 0,747. Лучшее дерево — `max_depth` = 10, `min_samples_leaf` = 100: 0,780. Лучшая линейная модель — Lasso, 0,800.
* Результаты линейных моделей и исследований предобработки и кодирования совпали с предыдущим этапом, в таблицах добавился только столбец `train_mae`.
* Сверка признаков: наибольшее относительное расхождение 5·10⁻⁷. Код `src/features.py` воспроизводит таблицу признаков с точностью до её округления до 7 значащих цифр.

Решающее дерево без ограничения размера листа (`min_samples_leaf` = 1):

| `max_depth` | MAE на обучении | MAE на проверке |
|---|---|---|
| 3 | 0,839 | 0,851 |
| 5 | 0,756 | 0,808 |
| 10 | 0,502 | 0,824 |
| 20 | 0,063 | 0,919 |
| без ограничения | 0,000 | 0,936 |

Валидация без группировки по исходнику:

| Модель | С группировкой | Без группировки | Разница |
|---|---|---|---|
| Медиана | 1,026 | 1,026 | 0,000 |
| Линейная регрессия | 0,810 | 0,821 | +0,011 |
| Решающее дерево, `max_depth` = 10, `min_samples_leaf` = 100 | 0,780 | 0,771 | −0,009 |
| KNN, manhattan, 3 соседа, веса по расстоянию | 0,792 | 0,752 | −0,040 |

| KNN, manhattan, 20 соседей, веса по расстоянию | 0,747 | 0,739 | −0,008 |
| Random Forest, `max_features` = 0,33, `min_samples_leaf` = 3 | 0,688 | 0,684 | −0,004 |

## Выводы

* Дерево показывает типичную картину переобучения: с ростом глубины ошибка на обучении падает до нуля, а на проверке после глубины 5 растёт. Ограничение листа 100 объектами останавливает рост дерева раньше, чем ограничение глубины: при `max_depth` 10, 20 и без ограничения результат одинаковый, 0,780. Одиночное дерево лишь немного лучше линейных моделей.
* У KNN оптимум находится при 10–20 соседях. При 3 соседях модель переобучается (0,792), при 100 слишком сглаживает (0,776). Манхэттенское расстояние лучше евклидова при любом числе соседей на 0,01–0,02: сумма модулей меньше зависит от отдельных признаков с большими отклонениями. При весах по расстоянию ошибка на обучении равна нулю, потому что ближайшим соседом объекта оказывается он сам.
* Random Forest — лучшая модель этапа: 0,688 против 0,800 у Lasso при втрое меньшем разбросе по фолдам. Ограничение листа 3 объектами лучше, чем 1 и 10; `max_features` 0,33 и 0,5 дают одинаковый результат, `sqrt` хуже примерно на 0,009. Отдельные деревья леса переобучены, но усреднение 300 деревьев на случайных подвыборках снижает дисперсию прогноза.
* По сравнению с Lasso лес сильнее всего снижает ошибку на шумовых вариантах (`_2` с 0,21 до 0,10, `_3` с 0,48 до 0,38) и на `_4` (с 1,05 до 0,84). На размытии `_1` и сжатии `_5` выигрыш небольшой (с 1,09 до 1,02 и с 1,17 до 1,12), и на эти два варианта приходится 62 % ошибки леса. На `_4` лес всё ещё уступает медиане (0,84 против 0,77).
* Без группировки по исходнику сильнее всего завышается качество KNN с малым числом соседей: среди ближайших соседей оказываются другие варианты того же снимка, и лучшим становится 10 соседей вместо 20. Для дерева и леса разница не превышает разброса по фолдам: варианты одного исходника искажены по-разному, и запомнить снимок по их признакам трудно. Утечка невелика, но меняет выбор параметров, поэтому модели подбираются на разбиении с группировкой.
* Оценка леса на кросс-валидации (0,688) выше ошибки на test (0,633 и 0,663), то есть валидация с группировкой не завышает качество. Разница между public и private объясняется различием частей test, на которых они считаются.
