# Веса нейросетей PSNR-IQA

В папке 20 моделей Keras, по пять фолдов для каждой из четырёх сетей. Их обучили в [отдельном прогоне Kaggle](https://www.kaggle.com/code/dxdfai/psnr-iqa-neural-weights), версия 1. Экспорт занял 8 ч 37 мин. Оценки сабмита № 58765896 относятся к полному прогону версии 3, который сохранял прогнозы без чекпойнтов.

| Модель | Вход | Фолды | CV MAE, дБ |
|---|---|---:|---:|
| [mlp_silu](mlp_silu/) | 155 признаков, SiLU | 5 | 0,637270 |
| [mlp_elu](mlp_elu/) | 155 признаков, ELU | 5 | 0,635758 |
| [cnn_efficientnet](cnn_efficientnet/) | Полный RGB-кадр | 5 | 0,493255 |
| [cnn_efficientnet_crop](cnn_efficientnet_crop/) | Вырезки при обучении, полный RGB-кадр при инференсе | 5 | 0,584738 |

`fold_N.keras` содержит архитектуру и веса модели. В `fold_N.json` записаны параметры предобработки фолда, среднее и стандартное отклонение PSNR, MAE и SHA-256. Для MLP там также указан порядок 155 признаков. Все 20 моделей сверены с SHA-256 из Kaggle. [Список файлов и суммы](manifest.json). [Таблица MAE](neural_cv_mae.csv).

Файлы моделей занимают 166,1 МиБ и хранятся через Git LFS. Если после клонирования появились только текстовые указатели, выполните `git lfs pull`. Модели сохранены в Keras 3.13.2.

## Инференс одной сети

Откройте модель с `keras.models.load_model(model_path, compile=False)`. Для CNN передайте PNG как RGB в диапазоне 0–255 с осью батча, сохранив разрешение. Нормализация пикселей уже входит в EfficientNet. Для MLP рассчитайте 155 признаков, расположите их как в `columns` и примените преобразование:

```python
x = np.clip(x, metadata["lower"], metadata["upper"])
x = ((x - metadata["feature_mean"]) / metadata["feature_scale"]).astype("float32")
```

Для обеих архитектур переведите выход обратно в децибелы:

```python
psnr = model(x, training=False).numpy().reshape(-1)
psnr = psnr * metadata["target_std"] + metadata["target_mean"]
```

Вычислите прогноз отдельно для каждого фолда с его собственными параметрами предобработки и усредните пять результатов. Для всего стекинга также нужны три бустинга и метамодель; этот экспорт содержит только нейросети.
