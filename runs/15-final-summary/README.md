Выбранный LightGBM-стекинг прогона 11 даёт CV MAE **0,450787**, Kaggle public **0,41641** и private **0,41627**. Из моделей на пикселях лучший результат показала EfficientNetB0 на целом кадре (**0,492996** CV). Показанные архивные оценки отличаются составом входа и, для подобранного LightGBM, разбиениями. Парное сравнение комбинаций берётся целиком из прогона 12. Оценка метамоделей на готовых OOF имеет ограничение, описанное в [прогоне 13](../13-linear-ensemble/README.md).

На OOF выбранного ансамбля вариант `_1` имеет MAE 0,633, а `_2` — 0,088. Выше 40 дБ всего 35 изображений из 13 210, их MAE достигает 11,327 дБ. График остатков показывает занижение прогноза в этой части диапазона.

Для полного запуска откройте ноутбук на Kaggle, подключите PSNR-IQA, GPU и Internet On для официальных весов ImageNet. Локальный запуск читает каталог PSNR_DATA_DIR (по умолчанию data). В ноутбуке предусмотрен диагностический режим PSNR_SMOKE=1, стандартный запуск использует весь датасет.

Архивная сводка ранее проверена по 13 210 строкам OOF. CSV из 3 310 уникальных изображений, собранный из архивных прогнозов, совпал по SHA-256 с сабмитом № 58445233. Это проверка архивного результата. У нового обучения CV и прогнозы могут отличаться.

## Результаты полного запуска

Версия 3 выполнилась на Tesla T4 примерно за 8 ч 55 мин. Все признаки и модели рассчитаны из исходного PSNR-IQA. CV MAE подтверждена по 13 210 OOF-прогнозам. Файл из 3 310 строк оценён Kaggle после завершения соревнования.

| Прогон | CV MAE, дБ | Kaggle public | Kaggle private | Сабмит |
|---|---:|---:|---:|---:|
| Полный запуск ноутбука, v3 | **0,456034** | **0,41615** | **0,41949** | 58765896 |
| Исторический стекинг, прогон 11 | 0,450787 | 0,41641 | 0,41627 | 58445233 |

Из отдельных моделей в полном запуске лучше всего сработала EfficientNetB0 на целых кадрах, MAE 0,498874 дБ. Стекинг дал 0,456034 дБ. Прогнозы полного запуска имеют меньшую ошибку на public, а исторический прогон — на private. Это результаты двух запусков одного подхода.

Значения выше относятся к завершённой версии 3. При повторном обучении на GPU значения могут немного отличаться.
